概要

受注時に希望配送時間帯（午前 / 14-16 時 / 16-18 時 / 18-21 時）を任意で指定できるようにします（ 希望配送時間帯の指定 (CR_001) ）。

変更内容

  • 変更要求の need タイプ cr とリンク changes を追加しました

  • FR_001、ENT_004、TBL_001、SCR_003、API_001 に時間帯を追加しました

  • TC_016 を追加しました

影響調査

トレース図で FR_001 の上下をたどり、関係する need を拾いました（スナップショットを docs/change_requests/snapshots/ に保存しています）。

確認したこと

  • ./build.ps1 が警告なしで通ること

  • カバレッジ・抜け漏れチェック に新しい抜け漏れが出ていないこと

suzuki が返信（13:55）

いい質問です。形式は相手との合意なしには変えられません。 列は末尾に「任意列」として足し、列がない今の形式（v1）も受け付けるようにしてください。そうすれば、取引先が対応するまで待たずに稼働できます。 取引先との調整は営業本部の仕事なので、 プロジェクト概要書 の未決事項に載せておいてください。

suzuki が docs/basic_design/batches.rst にコメント

もう 1 点。時間帯を指定しても、運送会社に伝わらなければ配達は時間どおりになりません。 BAT_002（送り状データ送信）は今、受注を読んでいませんよね。CRUD 図にも印がないので、図を見ても気づけないところです。業務フロー図の「データが外に出ていくところ」を追ってみてください。

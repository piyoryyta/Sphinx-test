3. 画面定義
-----------

.. scr:: ログイン・メニュー
   :id: SCR_001
   :status: review
   :owner: 鈴木
   :realizes: NFR_005

   ユーザー ID とパスワードでログインする。ログイン後はロールに応じて使えるメニューだけを表示する。

.. scr:: 受注一覧
   :id: SCR_002
   :status: review
   :owner: 鈴木
   :realizes: FN_009, FN_003

   受注番号・顧客・受注日・状態で検索し、一覧を表示する。行を選ぶと SCR_003 で詳細を開く。
   一覧から受注を取り消せる。

.. scr:: 受注登録・変更
   :id: SCR_003
   :status: review
   :owner: 鈴木
   :realizes: FN_001, FN_003, FN_004

   受注ヘッダ（希望配送時間帯を含む）と明細を入力する。保存すると在庫が引き当てられ、引当結果が明細ごとに表示される。
   詳細は :doc:`../detailed_design/order_entry_screen` を参照。

.. scr:: 受注取込
   :id: SCR_004
   :status: review
   :owner: 鈴木
   :realizes: FN_002

   受注 CSV をアップロードして取り込む。取込件数・エラー件数と、エラー行の内容を表示する。

.. scr:: 在庫照会
   :id: SCR_005
   :status: review
   :owner: 鈴木
   :realizes: FN_005

   商品コード・商品名で検索し、実在庫・引当済数・有効在庫を表示する。

.. scr:: 出荷指示
   :id: SCR_006
   :status: review
   :owner: 鈴木
   :realizes: FN_006

   出荷予定日を指定して対象の受注を一覧表示し、まとめて出荷指示を行う。ピッキングリストと納品書を出力する。

.. scr:: 出荷実績登録
   :id: SCR_007
   :status: review
   :owner: 鈴木
   :realizes: FN_007

   出荷番号のバーコードを読み取って出荷完了を登録する。ハンディ端末の小さな画面でも操作できるレイアウトにする。

.. scr:: 請求締め
   :id: SCR_008
   :status: review
   :owner: 鈴木
   :realizes: FN_008

   締め日と対象顧客（締め日が一致する顧客）を確認して請求締めを実行する。処理はバックグラウンドで行い、完了後に請求書 PDF をダウンロードできる。

.. scr:: マスタメンテナンス
   :id: SCR_009
   :status: draft
   :owner: 鈴木
   :realizes: FN_010

   顧客・商品・ユーザーのタブを切り替えて、検索・登録・変更を行う。

成果物一覧
==========

本プロジェクトで作成する成果物と、その状態の一覧です。
件数は need（ID 付きの要素）をビルドのたびに数え直しています。手で数字を書き換える必要はありません。

ステータス集計
--------------

.. list-table::
   :header-rows: 1

   * -
     - draft（作成中）
     - review（レビュー中）
     - approved（承認済み）
     - 合計
   * - 件数
     - :need_count:`status == 'draft'`
     - :need_count:`status == 'review'`
     - :need_count:`status == 'approved'`
     - :need_count:`True`

レビュー待ちの need
-------------------

.. needtable::
   :filter: status == 'review'
   :columns: id;title;type_name as "種別";owner as "担当"
   :style: table
   :sort: id

.. newbie:: このページの使い方

   レビュー依頼を受けたら、まず「レビュー待ちの need」の表を見てください。
   自分の担当分を書き終えたら、その need の ``:status:`` を ``draft`` から ``review`` に変えてビルドすると、この表に載ります。

よくある質問（FAQ）
===================

ドキュメント・業務
------------------

Q. 業務要件と機能要件の違いがわかりません。
   業務要件は「業務として何ができればよいか」、機能要件は「そのためにシステムが何をするか」です。
   :doc:`../requirements/business_requirements` の新卒メモに例があります。

Q. 受注の取消は「削除」ではないのですか？
   受注全体の取消は、データを消さずに状態を「取消」にします（論理削除）。
   取消した受注も、後から「いつ、なぜ取り消したか」を調べられるようにするためです。CRUD 図で受注（ENT_004）に D がないのはこのためです。

Q. 1 つの受注を何回かに分けて出荷（分納）できますか？
   できません。今回のスコープでは「受注 1 件 = 出荷 1 件」です（ :need:`ENT_006` ）。分納は将来の検討事項です。

Sphinx-Needs
------------

Q. ビルドすると「unknown link target」という警告が出ます。
   ``:satisfies:`` などに書いた ID が存在しません。ID の打ち間違い（ ``FR_01`` と ``FR_001`` など）を確かめてください。

Q. 一覧表に、新しく追加した need が出てきません。
   ``needtable`` の ``:types:`` や ``:filter:`` の条件に合っているか確かめてください。
   それでも出ない場合は ``./build.ps1 -Clean`` で全体をビルドし直してください。

Q. トレース図が表示されず、「dot command cannot be run」という警告が出ます。
   Graphviz が入っていません。 ``winget install Graphviz.Graphviz`` で入れてください。

Q. ``:status:`` に ``done`` と書いたらビルドが失敗しました。
   ステータスは ``draft`` / ``review`` / ``approved`` の 3 つだけ使えます（ ``docs/conf.py`` の ``needs_fields`` で制限しています）。

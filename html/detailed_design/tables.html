🔰 新卒メモ: CHECK 制約はプログラムのバグからデータを守る

画面や API でチェックしていても、プログラムにバグがあれば不正な値が入ることがあります。 allocated に「0 〜 on_hand」の CHECK 制約を付けておけば、バグがあっても在庫がマイナスになる前に DB がエラーで止めてくれます。
